GRADEA WEBSITE — START HERE

1. Unzip the folder.
2. Open index.html in your browser to preview.
3. Replace placeholder video, album and social URLs in index.html with your real links.
4. Replace placeholder album art with your own image files when ready.
5. Create a public GitHub repository named YOURUSERNAME.github.io and upload index.html, style.css, and script.js to its root.
6. In repository Settings > Pages, select Deploy from a branch, main, /(root).
7. In Settings > Pages > Custom domain, enter itsgradea.com. Follow GitHub's current custom-domain instructions for apex DNS records in GoDaddy. Wait for DNS to propagate and enable Enforce HTTPS when available.
8. Add a file named CNAME containing exactly: itsgradea.com (GitHub may create this automatically when using Pages settings).

IMPORTANT: Links in this demo are placeholders. Do not publish before updating them. The preview uses abstract CSS graphics rather than your real videos/artwork.

GitHub Pages documentation: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
