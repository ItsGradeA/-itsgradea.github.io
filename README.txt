GRADEA — WEBSITE V2

UPLOAD TO GITHUB PAGES
1. Extract this ZIP.
2. In the ItsGradeA/itsgradea.github.io repository, replace index.html, style.css, and script.js, and upload the assets folder.
3. Ensure index.html and assets/ are at the repository root.
4. Commit changes and wait for GitHub Pages deployment.

This version uses your skyline video (compressed for faster loading), your supplied Apple Music/Spotify artist links, and social profile links based on @ItsGradeA. Confirm the YouTube/Threads/TikTok profile destinations yourself.

Apple Music artwork and releases load in visitors' browsers from Apple's public iTunes Lookup API. The API may sometimes be unavailable or change its response; a fallback artist link is provided.

The Instagram cards are intentionally not represented as an automatic feed. They link to your Instagram Reels and TikTok profiles until an authorized API integration is implemented. No access tokens are included in this public repository.

This version is free to host on GitHub Pages. The skyline video is a compressed excerpt from your uploaded footage.
